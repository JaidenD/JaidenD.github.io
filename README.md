# JaidenD.github.io

My website, *Applying Geometry*: a home page plus a blog for math posts written in Markdown + LaTeX.

## Writing a post

1. Add a Markdown file to `posts/`, e.g. `posts/galois-theory.md`. The file name becomes the
   link (`post.html?p=galois-theory`). Or let the helper create one from a template:

   ```bash
   python3 tools/site.py new "Galois theory"
   ```

2. Start it with front matter, then write:

   ```markdown
   ---
   title: Galois theory
   date: 2026-11-26
   summary: One or two sentences for the home page.
   status: incomplete
   ---

   Let $K/F$ be a finite extension. Then
   $$
   [K : F] = [K : E]\,[E : F].
   $$

   ::: theorem Fundamental theorem
   Subgroups of $\Gal(K/F)$ correspond to intermediate fields.
   :::
   ```

   Math is plain LaTeX: `$...$` inline, `$$...$$` display, `\begin{align}` and friends,
   `\label` / `\eqref`. There are also theorem/proof/definition blocks, footnotes, code,
   tables, images and videos. **[`posts/formatting-guide.md`](posts/formatting-guide.md) shows
   everything.** `status` is optional (it puts a small "incomplete" label on the post).

3. Preview it while you write:

   ```bash
   python3 tools/site.py serve
   ```

   Then open <http://localhost:8000>. A post page re-renders by itself every time you save the
   file. Posts with `draft: true` (like the formatting guide) show up here but not on the live site.

4. Publish: commit and push to `master`, or upload the `.md` file on GitHub with
   **Add file → Upload files** into the `posts` folder.

## Publishing setup (once)

In the repository on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
From then on every push to `master` rebuilds the list of posts and publishes the site, so a post
appears as soon as its file is on GitHub.

If you'd rather keep "Deploy from a branch", that works too, but then the list of posts only
updates when you run `python3 tools/site.py build` (or `serve` / `new`, which do the same) before
pushing, because `posts/index.json` has to be committed.

## What's where

| Path | What it is |
|------|------------|
| `index.html` | Home page (intro, research, contact). The blog list fills itself in |
| `post.html` | Page that displays a post |
| `posts/*.md` | The posts. Put a post's images/videos in a folder next to it, e.g. `posts/galois-theory/` |
| `posts/index.json` | List of posts, generated by `tools/site.py`. Don't edit by hand |
| `style.css` | Colours and fonts. Change `--font-body` for an all-Courier look |
| `blog.js` | Markdown + MathJax rendering. `MATH_MACROS` at the top holds shortcuts like `\R` |
| `tools/site.py` | `new`, `serve` and `build` commands (Python 3.8+, nothing to install) |
| `.github/workflows/deploy.yml` | Publishes the site on every push to `master` |
| `Chaotic_Sys_blog/`, `PDEsymm_blog/`, ... | Images, videos and code for the older posts. Their old `.html` pages now redirect to the new ones |
